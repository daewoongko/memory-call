# 음성 클론 녹음 대본

## 녹음 조건

- 조용한 방, 창문 닫고, 에어컨/선풍기 끄기
- 마이크와 입 사이 15~20cm (에어팟 말고 유선 이어폰 마이크 이상)
- **평소 할아버지랑 통화할 때 톤으로.** 아나운서처럼 읽으면 클론 결과도 딱딱해진다
- 조금 느리게. 이 서비스의 대상은 청력이 떨어진 노인이다
- 한 섹션 끝날 때마다 2초 쉬기 (편집용)
- 파일: `data/voice/daewoong_raw.wav` (48kHz, 모노, WAV)

목표 분량 **3분**. ElevenLabs Instant Clone은 1분이면 되지만, 여유분이 있어야 잘린 구간 버리고 쓸 수 있다.

## 검증 방법 (D1)

녹음 후 클론 만들고 **아래 3문장**을 합성해서 들어봐.

1. `할아버지, 저녁 약부터 같이 챙기자.`
2. `오늘 일정은 확인해보고 알려줄게.`
3. `넘어지셨구나. 지금 일어나실 수 있어?`

체크 포인트:
- [ ] "할아버지"의 받침이 뭉개지지 않는가
- [ ] 문장 끝이 로봇처럼 뚝 끊기지 않는가
- [ ] 억양이 한국어답게 올라가고 내려가는가
- [ ] 감정 톤이 3문장에서 각각 다르게 들리는가

**2개 이상 걸리면 미련 없이 OpenAI TTS로 전환.** 발표에서는 "음성 클론은 로드맵"으로 정리하고 나머지에 시간 쓰는 게 이득이다.
