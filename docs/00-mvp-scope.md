# MVP 범위

## 1. 제품 목표

가족이 직접 영상통화를 받지 못했을 때 AI가 제한된 시간 동안 통화를 이어 주고,
검증된 가족 기억과 구조화된 생활 정보를 사용해 정서적 대화를 제공한 뒤 보호자가
확인해야 할 내용을 전달한다.

MVP의 성공은 얼굴 생성의 화려함이 아니라 다음 세 가지로 판단한다.

1. 느린 발화를 끊지 않으면서 안정적으로 대화할 수 있는가
2. 확인되지 않은 기억과 약 정보를 사실처럼 생성하지 않는가
3. 통화 결과가 실제 보호자의 확인과 연락으로 이어지는가

## 2. 이 MVP의 제약

| 항목 | 값 |
|---|---|
| 개발자 | 1명 (프론트·백·AI 전부) |
| 기간 | 2주 |
| 목적 | SKT Fly AI 프로그램 발표 데모 |
| 실행 환경 | localhost (배포 없음) |
| LLM | Gemini 무료 티어 (OpenAI 호환 엔드포인트) |

**시간이 부족하면 다른 걸 자르고 안전 레이어를 지킨다.** 근거는
`docs/02-safety-policy.md`.

## 3. 대상 사용자

### 치매 노인

- 초기 또는 경도·중등도 치매 증상이 있는 사용자
- 보호자가 사전에 서비스 사용을 설정한 사용자
- 태블릿의 단순한 통화 인터페이스를 사용할 수 있는 사용자

### 가족·보호자

- 통화 수신, 가족 페르소나 설정 및 생활 정보를 관리하는 사용자
- 신규 기억, 위험 알림과 통화 리포트를 검토하는 사용자
- 데이터 사용 동의와 철회를 관리하는 사용자

초기 파일럿의 참여·제외 조건은 의료·법률·윤리 검토 후 확정한다. 현재 seed
데이터는 전부 가상 인물이다.

## 4. 데모 시나리오 (이것만 완성하면 된다)

```text
할아버지가 손자에게 영상통화
→ 15초 무응답
→ AI 안내 후 연결                        ← AI 고지 단계
→ 어린 시절 얼굴이 현재 얼굴로 모핑
→ 안부
→ "오늘 집에 오니?"                      ★ 거짓 약속 방지 발동
→ 같은 질문 3회 반복 (짜증 없이)
→ 확인된 추억 회상
→ 저녁 약 확인
→ "어지러워" 위험 발화
→ 보호자 알림
→ 종료
→ 보호자 리포트
```

**이 시나리오 1개 밖은 D10까지 손대지 않는다.** 명세가 잘 쓰여 있어서 "이것도
되겠는데" 병이 생긴다.

대본은 `docs/demo_script.md` (5막 3분).

## 5. MVP 필수 기능

### 통화

- 노인용 원터치 통화
- 보호자 수신 요청
- 미응답 시 AI 통화 전환
- **AI임을 알리는 고지 단계** (건너뛸 수 없음)
- 영상 실패 시 사진 전환 폴백

### AI 대화

- 브라우저 음성 인식·합성 (Chrome 필수)
- 느린 발화용 개인별 대기시간 (`elder_profiles.speech_wait_time_ms`)
- 가족 호칭·말투 설정 (`personas`)
- 반복 질문 탐지와 안정적인 반복 응답
- AI 정체성 질문과 통화 거부 처리

### 기억 안전성

- `verified` / `partial` / `unverified` / `prohibited` 네 상태
- 검색된 기억만 사실 표현에 사용
- 응답별 기억 출처 기록 (`utterances.used_memory_ids`)
- 미확인 기억의 보호자 승인 (`recall_reviews`)
- 금지 기억 취급 규칙 (배제가 아니라 명시적 취급)

### 생활 돌봄

- 구조화된 복약 일정 (`medications`)
- 본인 응답 / 미확인 / 거부 / 중복 위험 / 보호자 확인 상태
- 약 종류·용량을 LLM이 생성하거나 변경하지 못하도록 차단

### 안전 및 보호자

- 위험 발화 탐지와 보호자 알림
- 통화 요약과 주요 사건 리포트
- 실제 연락 권장
- 정책 위반 기록 (`utterances.safety_flags`)

### 영상 개인화

- 연령별 사진의 **사전 생성** 모핑 (통화 중 생성하지 않음)
- 볼륨 기반 2장 전환 립싱크
- 표정 루프 (talking / concerned)

## 6. MVP 제외

- 치매 단계·우울증·질병 진단
- 의료적 예측 점수
- 약 사진만으로 약품·복용량 판별
- 자동 긴급 신고
- 완전한 어린 시절 목소리 복원
- 실시간 고해상도 생성형 얼굴 영상
- 스마트 약통·웨어러블·메신저 연동
- 여러 가족 페르소나의 자동 전환
- 동의받은 데이터를 범용 AI 모델 학습에 사용하는 기능

기술 스택 차원의 제외 결정은 `docs/01-decisions.md` 를 볼 것.

## 7. 비기능 요구사항

### 성능

- 발화 종료 후 첫 음성 응답 시작 목표 3초 이내
- LLM 첫 문장이 나오는 즉시 TTS 시작 (스트리밍). **설계 초기에 넣어야 나중에
  못 고친다**
- 기억 검색은 SQLite 직접 조회 (기억 30개 규모에 벡터DB 불필요)

### 신뢰성

- LLM·영상 실패 시 안전한 폴백으로 전환 (`docs/02-safety-policy.md` 12절)
- 리포트 생성 실패는 재시도 가능해야 하며 통화 원본 상태와 분리한다
  (`GET /api/calls/{id}/report?regenerate=true`)
- 모델이 실패해도 리포트의 숫자는 나온다 (집계는 규칙)

### 추적 가능성

- AI 응답, 검색 기억, 정책 결과를 기록한다 (`utterances`)
- 복약·위험 상태 변경은 시간을 기록한다
- 보호자 승인 전의 미확인 기억은 사실 데이터와 분리한다

## 8. 단계별 게이트

### Gate A: 대화 프로토타입 — 완료

- 터미널 대화가 중단 없이 완료된다 (`tools/chat.py`)
- 반복 질문 시나리오에서 부정적 표현이 발생하지 않는다
- 존재하지 않는 약속과 미확인 기억을 사실로 말하지 않는다

### Gate B: 안전 코어 — 완료 (통과율 91%)

- 복약 정보는 등록 데이터 밖의 용량을 생성하지 않는다
- 모든 사실성 응답에서 근거 기억 ID를 조회할 수 있다
- `tools/eval.py` 시나리오 22개가 회귀를 잡는다

### Gate C: 보호자 기능 — 완료

- 보호자가 기억을 승인·거부·금지할 수 있다
- 위험 알림과 통화 리포트가 기록된다

### Gate D: 개인화 — 부분 완료

- 모핑 인트로 mp4 사전 생성 (`tools/make_morph.py`)
- 표정 루프 (`tools/make_loops.py`)
- 음성 클론은 품질 미달로 보류, 브라우저 기본 TTS 사용

### Gate E: 폐쇄형 파일럿 — 미착수

- 윤리·개인정보·위험 대응 검토
- 참여자와 보호자에게 AI 사용 및 한계 설명
- **실제 가족 사진·음성·대화가 들어가는 시점부터 LLM 유료 티어로 이전**
  (무료 티어는 요청 내용이 모델 개선에 사용될 수 있다)
