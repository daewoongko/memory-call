# 얼굴 연령 변화 시스템

이 문서는 제품에 이미 포함된 연령 타임라인과 AI Hub 데이터로 개선 중인 후보
생성 실험을 구분하고, 현재 실행 가능한 범위를 하나의 기준으로 정리한다.

## 1. 제품에 이미 들어간 경로

검증 완료된 데모 타임라인은
`8 → 9 → 11 → 13 → 15 → 16 → 17 → 20 → 23 → 26 → 29 → 31 → 32`다.

| 단계 | 모델·기술 | 역할 | 학습 여부 |
|---|---|---|---|
| 입력 품질 검사 | OpenCV YuNet | 얼굴 수·크기·기울기·선명도·밝기 검사 | 고정 |
| 후보 사진 생성 | FLUX.2 Klein 4B Inpaint | 얼굴 영역을 목표 나이로 다시 그림 | 고정 |
| 개인 얼굴 유지 | Identity LoRA | 등록한 사람의 얼굴 특징을 생성기에 제공 | 사용자별 학습 |
| 성장 구조 보조 | FRAN residual U-Net | 턱·볼·하안면 등 성장 방향의 구조 가이드 | 데이터 실험 대상 |
| 신원 검증 | InsightFace | 생성 사진과 기준 사진의 얼굴 임베딩 비교 | 고정 |
| 연령 검증 | InsightFace·MiVOLO | 목표 나이 적합도를 독립적으로 추정 | 고정 |
| 구조 검증 | 3DDFA-V2 | 포즈 영향을 줄인 얼굴 구조 변화 확인 | 고정 |
| 키프레임 정렬 | YuNet 5점 랜드마크 | 눈과 얼굴 위치를 맞춰 흔들림 완화 | 고정 |
| 영상 보간 | RIFE ONNX | 승인된 연령 사진 사이의 중간 프레임 생성 | 고정 |
| 통화 아바타 | Anam | 현재 가족 얼굴을 말하는 영상으로 표현 | 공급자 모델 |

FRAN 결과는 완성 사진이 아니다. FLUX 생성 방향을 보조하는 구조 가이드이며,
FRAN 단독 출력을 제품 사진으로 사용하면 얼굴이 비현실적으로 보일 수 있다.

완성 자산은 다음 위치에 있다.

- 영상: `data/faces/morph.mp4`
- 검증 결과: `data/faces/morph.validation.json`
- QC 시트: `data/faces/morph_qc.png`
- 키프레임: `data/faces/aligned/age_path_final/`

## 2. 이번 개선의 목표

기존 방식은 한 번 성공한 연령 경로를 만들었지만, 새로운 사람에게 같은 품질을
안정적으로 재현하고 여러 후보 중 근거 있는 추천을 제공하는 자동화가 부족했다.
이번 실험은 생성 모델을 무조건 크게 재학습하는 작업이 아니라 다음 세 가지를
개선한다.

1. 목표 나이가 피부 톤 변화에 그치지 않고 아동 얼굴 구조로 보이게 한다.
2. 성인 얼굴의 신원을 유지하되 목표 나이 정확도와 균형을 맞춘다.
3. 자동 추천 한 장으로 확정하지 않고 네 후보와 추천 이유를 가족에게 제공한다.

## 3. 데이터 사용

### AI Hub 71415 — 안면 인식 에이징 이미지

- 동일 인물의 여러 연령 사진으로 연령 변화와 목표 8세 평가 구조를 만든다.
- 공식 Training 인물만 학습·튜닝에 사용하고 공식 Validation 인물은 최종 시험에
  남긴다.
- 사람 단위로 분리해 같은 인물이 학습과 평가 양쪽에 들어가지 않게 한다.
- 실제 8세 정답 사진은 후보 생성·자동 순위 학습에 노출하지 않고 마지막 평가에만
  연다.

### AI Hub 528 — 가족 관계 얼굴 이미지

- 가족 간 유사성과 동일 인물 보존을 구별하는 신원 선별기 연구에 사용한다.
- 생성기의 목표 나이 변환을 직접 학습시키는 데이터로 취급하지 않는다.

원본과 정렬 파생물은 `data/experiments/` 아래 로컬에만 두며 Git에 올리지 않는다.

## 4. 두 제품 모드

| 모드 | 입력 | 의미 |
|---|---|---|
| 현재 사진 추정 | 성인 사진만 | 어린 사진이 없는 사용자의 추정 후보 생성 |
| 어린 시절 사진 보조 | 성인 사진 + 품질을 통과한 어린 사진 | 실제 어린 시절 단서를 별도 LoRA로 보조 |

어린 사진은 `train_primary`, `reference_only`, `reject`로 나눈다. 얼굴 픽셀 크기,
선명도, 밝기, 대비, 기울기를 자동 검사하고 가림·과한 표정·복잡한 배경은 사람이
확인한다. 낮은 화질을 단순 확대했다고 학습 가능 사진으로 승격하지 않는다.

어린 시절 사진 보조 모드에서도 일부 사진만 학습하고 최소 한 장은 평가용으로
봉인한다. 성인 신원 LoRA와 어린 근거 LoRA를 섞어 하나로 만들지 않는다.

## 5. 네 후보 생성 경로

| 후보 | 생성 방식 | 목적 |
|---|---|---|
| 직접 | 성인 기준 사진에서 바로 8세 생성 | 가장 단순한 비교 기준 |
| 순차 | 현재 나이부터 적응형 중간 나이를 거쳐 8세로 이동 | 큰 연령 점프 완화 |
| FRAN 가이드 | 순차 경로에 FRAN 구조 힌트를 추가 | 아동 얼굴 구조 변화 보강 |
| 어린 사진 보조 | 순차 경로와 성인·어린 근거 LoRA를 함께 사용 | 실제 어린 시절 단서 활용 |

나이 간격은 고정 목록이 아니라 이전 후보의 통과 여부와 얼굴 변화량을 보고
조정한다. 기준에 미달하면 합격선을 낮추지 않고 중간 나이를 추가하거나 다시
생성한다.

단일 실행 도구는 `tools/aihub71415_four_candidate_pilot.py`다.

```powershell
# 준비 상태와 생성 결과 확인
.\.venv\Scripts\python.exe tools\aihub71415_four_candidate_pilot.py status `
  --case-id childhood_assisted_0137

# 필요한 LoRA만 이어 학습하고 네 후보 생성 및 검토 화면 작성
.\.venv\Scripts\python.exe tools\aihub71415_four_candidate_pilot.py run `
  --case-id childhood_assisted_0137 `
  --train-steps 300
```

학습 도중 체크포인트가 있으면 `latest`에서 이어서 실행한다. 완료된 Identity LoRA는
다시 학습하지 않으며, 누락된 어린 근거 LoRA만 학습할 수 있다.

검토 화면은 다음 파일이다.

```text
data/experiments/aihub71415_full/two_mode_pilot_v2/
  four_candidate_pilot/childhood_assisted_0137/review/index.html
```

파일을 직접 여는 대신 프로젝트 루트에서 정적 서버를 띄우는 편이 안전하다.

```powershell
.\.venv\Scripts\python.exe -m http.server 8090
```

그 뒤 `http://127.0.0.1:8090/data/experiments/.../review/index.html`을 연다.

## 6. 후보 선별과 사용자 선택

얼굴 미검출, 다중 얼굴, 심한 흐림·노출 문제는 먼저 하드 게이트로 제거한다.
통과 후보는 다음 근거로 순위를 계산하되 최종 사진은 사용자가 고른다.

- 목표 나이 적합도
- 현재·과거 기준 사진에 대한 신원 보존도
- 얼굴 인식에 사용할 수 있는 수준의 이미지 품질
- 인접 연령 사진과의 연속성(경로가 있을 때만)

논문이 합의한 보편적 고정 가중치는 없으므로 임의 비율을 사용하지 않는다.
블라인드 쌍대비교에서 사람이 고른 결과를 비음수·합 1의 가중치로 학습하고,
사람 단위 교차검증으로 새 사람에게도 선택을 예측하는지 확인한다. 실제 8세 정답은
이 가중치 학습에 쓰지 않는다.

추천 이유는 LLM이 만들지 않고 수치 차이로 조립한다.

- `목표 8세에 가장 가까운 후보`
- `기준 사진의 얼굴 특징이 가장 안정적으로 남은 후보`
- `나이 적합도와 신원 보존의 균형이 가장 좋은 후보`
- `자동 추천 차이가 작아 가족의 직접 선택이 필요함`

## 7. 현재 실행 상태

- 두 모드의 품질 게이트와 사람 단위 누출 검사는 구현됐다.
- 시험 인물 `childhood_assisted_0137`의 Identity LoRA와 어린 사진 보조 LoRA 학습이 완료됐다.
- 직접·순차·FRAN 가이드·어린 사진 보조 후보 4개가 모두 생성됐다.
- 네 후보를 생성법과 자동 점수를 숨기고 비교하는 검토 화면이 생성됐다.
- 직접 생성 기준 후보는 앞선 측정에서 목표 8세보다 성인에 가깝게 판정됐다.
- 네 후보 모두 사람의 연령 적합도·신원 보존도 평가와 자동 순위 학습은 아직 완료되지 않았다.
- 실제 8세 정답은 봉인 상태이며 후보 생성이나 자동 추천에 사용하지 않았다.

따라서 “한 사람을 준비하고 필요한 LoRA를 학습한 뒤 네 경로를 실행하고 블라인드
검토 화면을 만드는 단일 진입점”은 동작한다. 다음 단계는 이 한 사람의 네 후보를
먼저 평가해 연령 적합도가 부족한 경로를 탈락시키고, 통과한 경로만 여러 사람으로
확대하는 것이다. 봉인한 실제 8세 사진은 이 선택이 끝난 뒤 최종 성능 비교에만 연다.
