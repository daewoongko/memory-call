# 최종 시연 실행 가이드

이 문서는 2026-08-31 발표 영상과 현장 시연의 기준입니다. 화면에 없는 사실이나
LLM이 보장하지 않는 정확한 문장을 약속하지 않습니다.

## 시연 전 확인

```powershell
.\.venv\Scripts\python.exe tools\demo_reset.py
.\.venv\Scripts\python.exe -m unittest tests.test_start_seed tests.test_memory_verification
```

- 대표일: 2026-08-31
- 통화: 40통, 총 160분
- 기억: `mem_016`, `verified`, 통화 사용 허용
- 모핑: 8→9→10→11→12→15→17→20→24→28세, 24.2초
- TTS: ElevenLabs 0.93 속도
- 보호자 셀프뷰: 어르신 화면에 표시하지 않음

## 전체 흐름

### 1. 전화 시작

발표자:

> 어르신이 가족에게 전화를 겁니다. 연결을 기다리는 동안 낯선 벨소리 대신 가족이
> 선택한 자연 배경음과 짧은 안내가 나오고, 손자의 어린 시절부터 현재까지 얼굴이
> 천천히 이어집니다.

음원에는 “할아버지, 지금 연결하고 있어요. 편하게 기다려 주세요.” 안내가 앞뒤로
두 번 들어 있습니다. 별도의 현장 멘트로 음원을 덮지 않습니다.

모핑을 보는 어르신 녹음 예시:

> 어? 우리 대웅이가 이렇게 컸구나. 얼굴이 변하니 참 신기하네.

이 문장은 영상 반응용 녹음이며 LLM 입력으로 사용할 필요는 없습니다.

### 2. AI 기억통화 시작

가족이 받지 않으면 24.2초 인트로 직후 AI 기억통화가 이어집니다. 현재 28세 얼굴의
말하는 아바타가 보이고, 어르신 자신의 작은 셀프뷰는 표시하지 않습니다.

어르신:

> 여보세요? 대웅이 맞지? 밥은 먹었니?

기대 응답의 의미:

- 안부를 따뜻하게 받는다.
- 확인할 수 없는 어르신의 식사 상태를 단정하지 않는다.
- “진짜 대웅 본인”이라고 속이지 않는다. 정체성을 재차 물으면 대웅이가 준비한
  기억통화라고 설명한다.

LLM의 단어 선택은 매번 조금 달라질 수 있습니다. 발표 자막에는 정확한 생성 문장
대신 위 행동 계약을 설명합니다.

### 3. 날짜 확인

어르신:

> 그런데 오늘이 며칠이지?

기대 응답의 의미:

- 서버가 제공한 현재 날짜 2026년 8월 31일을 짧고 천천히 안내한다.
- 화면의 날짜와 함께 확인하도록 돕는다.
- 등록되지 않은 방문 일정을 만들어내지 않는다.

“너 오늘 오는 날 아니냐?”는 등록된 일정이 없으므로 최종 시연의 고정 발화로
사용하지 않습니다. 이 질문을 하더라도 시스템은 방문을 약속하지 않고 가족에게
확인하겠다고 답해야 합니다.

### 4. 확인된 추억 대화

어르신:

> 네가 어릴 때 할아버지랑 강가에서 빨간 공 가지고 놀던 게 생각난다.

이 발화는 `mem_016`의 등록 내용과 일치합니다. 기대 응답의 의미:

- 강가 잔디밭, 작은 빨간 공, 어린 대웅이가 공을 안고 달려온 장면 범위 안에서만
  회상을 이어간다.
- 등록되지 않은 연도·날씨·동행인·약속을 덧붙이지 않는다.
- 통화 발화와 기억 ID를 근거로 그림일기와 리포트를 만든다.

### 5. 보호자 화면

발표자:

> 통화 뒤 보호자는 오늘의 그림일기와 분석 리포트를 확인합니다. 리포트의 수치는
> 임의의 원형 점수가 아니라 실제 40통의 발화 빈도와 근거 문장에서 계산됩니다.
> 새로 나온 이야기는 바로 추억으로 노출되지 않고 ‘확인이 필요한 이야기’에서
> 가족 확인을 거칩니다.

확인 순서:

1. 오늘 탭에서 8월 31일 그림일기 “대웅이와 강가 공놀이”를 연다.
2. 추억 탭에서 확인된 기억만 “함께 보는 추억”에 있는지 본다.
3. 분석 리포트에서 40통·160분과 실제 근거 발화를 확인한다.
4. 미확인 이야기가 확정 문장이나 확인 추억 카드로 노출되지 않는지 확인한다.

## 장애 시 설명

- Anam 실패: 얼굴 영상 없이 ElevenLabs 음성 대화는 계속됩니다.
- TTS 실패: 유료 요청을 무한 재시도하거나 다른 목소리로 몰래 바꾸지 않고 오류를
  표시합니다.
- WebRTC 실패: 어르신을 연결 화면에 남겨두지 않고 AI 통화로 인계합니다.
- LLM 응답 표현 차이: 정확한 대사 재현보다 등록 사실·안전 규칙 준수를 평가합니다.
