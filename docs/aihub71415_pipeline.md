# AI Hub 71415 연령 변환 실험 파이프라인

이 파이프라인은 `안면 인식 에이징 이미지 데이터(71415)`를 이용해 한국인 연령
변환의 구조 기준을 학습하고, 실제 8세 사진을 숨긴 상태에서 현재 생성기와 새
모델을 비교하기 위한 기반이다. 원본 얼굴과 파생 정렬 사진은 Git에 올리지 않는다.

## 1. 샘플 인덱싱

원본 ZIP을 풀지 않고 라벨과 이미지의 대응 관계만 기록한다.

```powershell
.\.venv\Scripts\python.exe tools\aihub71415_index.py `
  --archive "C:\path\to\Sample.zip" `
  --output-dir data\experiments\aihub71415_sample\index
```

전체 데이터가 원천·라벨 ZIP으로 나뉘면 라벨 ZIP을 `--archive`, 원천 ZIP을
`--image-archive`로 전달한다.

전체 904개 묶음을 한 번에 인덱싱할 때는 압축을 풀지 않고 데이터셋 루트를
전달한다. 파일 이름의 대소문자 차이와 일부 라벨에 포함된 `.png` 확장자는
정규화해서 원천 사진과 연결한다.

```powershell
.\.venv\Scripts\python.exe tools\aihub71415_index.py `
  --dataset-root "C:\path\to\118.안면 인식 에이징(aging) 이미지 데이터" `
  --output-dir data\experiments\aihub71415_full\index
```

## 6. FRAN 파인튜닝

FRAN 입력과 출력 구조는 유지한다. 입력은 RGB 3채널, 현재 나이 맵, 목표 나이
맵의 5채널이고 생성기는 원본에 더할 RGB residual을 예측한다. 생성기와
PatchGAN 판별기는 기존 공개 체크포인트에서 시작한다.

AI Hub 사진은 같은 사람이어도 표정·자세·조명·배경이 서로 다르다. 따라서 실제
과거 사진을 목표 픽셀로 직접 맞추는 `paired` 목적은 비교 실험으로만 두고,
기본값은 `distribution`으로 정했다.

- 고정 교사 FRAN 결과와 L1·LPIPS로 가까운 상태를 유지한다.
- AI Hub 실제 사진으로 판별기가 한국인 연령 분포를 학습한다.
- 생성기는 목표 나이 판별 손실을 작게 받아 촬영 조건을 복사하지 않고 분포만
  보정한다.
- 처음 50스텝은 판별기만 적응시키고 이후 생성기를 함께 갱신한다.
- 원본 `best_unet_model.pth`는 덮어쓰지 않고 실험 폴더에 생성기 전용 및 전체
  재개 체크포인트를 함께 저장한다.

학습 환경 준비:

```powershell
.\.venv-age\Scripts\python.exe -m pip install -r requirements-reaging.txt
```

512px 안전 파일럿:

```powershell
.\.venv-age\Scripts\python.exe tools\aihub71415_train_fran.py `
  --image-size 512 `
  --steps 200 `
  --discriminator-warmup-steps 50 `
  --max-train-pairs 5000 `
  --max-val-pairs 64 `
  --val-batches 8 `
  --output-dir data\experiments\aihub71415_full\training\pilot_512_200
```

`preview_before.jpg`와 `preview_after.jpg`를 먼저 비교하고, `metrics.jsonl`에서
검증 LPIPS와 `val_teacher_l1`을 확인한다. 교사 이탈이 커지거나 얼굴 표정·배경이
목표 사진 쪽으로 복사되면 해당 체크포인트를 채택하지 않는다. 이 게이트를 통과한
뒤에만 스텝 수를 늘린다.

5. 사람의 블라인드 선호 평가

기존보다 낮아지지 않고, 목표 나이 오차 또는 사람 평가가 개선될 때만 다음 장기
학습 후보를 서비스에 연결한다.

## 7. 5,000스텝 균형 학습과 최종 판정

전체 195,125쌍을 단순 무작위로 반복하면 사진이 많은 사람과 흔한 연령 구간이
학습을 지배한다. 이를 막기 위해 `balanced_age_gap_subject` 샘플러를 추가했다.

- 사람별 데이터 수의 역수로 가중하여 특정 인물이 과대표집되지 않게 한다.
- 목표 연령을 `0~5 / 6~10 / 11~17 / 18~29 / 30~44 / 45+`로 나눠 균형화한다.
- 연령 차이를 소·중·대 세 구간으로 나눠 큰 연령 변환도 계속 보게 한다.
- 서비스 핵심인 목표 8세 주변(6~10세)은 2배 가중한다.
- 극단 가중치는 0.1~10 범위로 제한한 뒤 평균 1로 정규화한다.

실제 기대 표집 비율은 목표 6~10세 29.37%, 나머지 연령 구간 각각
13.37~14.61%였고, 연령 차이 소·중·대는 각각 32.79%, 33.07%, 34.14%였다.
이 설정으로 512px, batch 1, AMP, 학습률 `1e-5`에서 5,000스텝을 실행했다.

| 항목 | 시작 | 3,500스텝 | 5,000스텝 |
|---|---:|---:|---:|
| 검증 L1 | 0.246416 | **0.246030** | 0.246121 |
| 검증 LPIPS | 0.680441 | **0.678756** | 0.679229 |
| 고정 교사 대비 L1 변화 | 0 | - | 0.002080 |

- 총 실행 시간: 2,307.7초(38분 28초)
- 평균 실행 시간: 0.462초/스텝
- 최대 할당 GPU 메모리: 1.689 GiB
- 내부 검증 최저점은 3,500스텝이었다.

내부 검증 사진은 실제 과거 사진과 촬영 조건이 달라 최종 판정에 충분하지 않다.
따라서 학습에 한 번도 쓰지 않은 공식 Validation 인물 중 정확한 8세 사진을 가진
62명을 대상으로, 각 인물의 가장 나이 든 성인 사진만 입력하고 실제 8세 사진은
정답 평가에만 사용했다. 모든 사진은 AI Hub 5점 라벨로 먼저 고정 정렬했으므로,
평가 단계에서 얼굴 검출기의 임계값을 다시 통과시키지 않고 같은 고정 좌표에서
InsightFace 임베딩과 나이 추정을 계산했다.

| 지표(62명 평균) | 기존 모델 | 3,500스텝 | 5,000스텝 |
|---|---:|---:|---:|
| 실제 8세 사진과 신원 유사도 | 0.31636 | 0.31743 | 0.31635 |
| 성인 입력과 신원 유사도 | 0.76991 | 0.78545 | 0.77940 |
| 목표 8세 나이 절대오차 | **16.58세** | 17.95세 | 17.73세 |
| 실제 8세 사진 대비 L1 | 0.22333 | 0.22267 | **0.22255** |
| 실제 8세 사진 대비 LPIPS | 0.70350 | **0.69734** | 0.69933 |

3,500스텝의 실제 8세 신원 유사도 증가는 `+0.00107`로 작고, 95% 부트스트랩
신뢰구간 `[-0.00146, +0.00359]`이 0을 포함했다. 반면 목표 나이 오차는
`+1.37세` 악화되었다. 성인 입력과의 유사도가 더 높아진 것은 신원 보존에는
긍정적일 수 있지만, 이번 실험에서는 얼굴이 충분히 어려지지 않은 결과와 함께
나타났다. 5,000스텝도 실제 8세 신원 유사도는 기존과 사실상 같고 나이 오차가
`+1.15세` 악화되었다.

따라서 **5,000스텝 후보와 3,500스텝 후보 모두 서비스 모델로 승격하지 않는다.**
기존 `best_unet_model.pth`도 덮어쓰지 않았다. 더 많은 스텝보다 다음 목적함수
변경이 먼저다.

1. 고정 교사 보존 손실의 비중을 낮추는 짧은 2단계 학습을 별도 실험한다.
2. 고정 InsightFace 임베딩의 신원 보존 손실을 추가한다.
3. 고정 나이 추정기의 목표 나이 손실을 추가하되, 추정기 편향을 확인하기 위해
   여러 나이 구간의 실제 사진으로 먼저 보정한다.
4. 표정·자세·조명이 가까운 동일 인물 쌍을 우선 표집하고, 품질이 낮거나 가림이
   큰 사진은 학습 비중을 낮춘다.
5. 8세 홀드아웃에서 실패가 큰 인물·연령 차이를 다음 학습의 hard example로
   재표집하되 공식 Validation 101명은 끝까지 학습에 넣지 않는다.

L1·LPIPS는 종단 사진의 표정·자세·조명 차이에 영향을 받으므로 보조 지표로만
사용한다. 다음 후보도 신원 보존, 목표 나이, 블라인드 사람 평가를 함께 통과해야
서비스에 연결한다.

## 8. 나이·신원 목적함수 개편과 운영 승격

단순 재구성 손실은 얼굴이 실제 8세에 가까워졌는지와 같은 사람인지 직접 측정하지
못했다. 이를 보완하기 위해 운영 모델 수를 늘리지 않는 **학습 전용 교사 두 개**를
별도로 만들었다. 생성 서비스에는 여전히 FRAN과 후처리 모델만 로드한다.

### 8.1 학습 전용 교사

| 교사 | 학습 데이터 | 역할 | 공식 검증 결과 |
|---|---|---|---:|
| 한국인 나이 교사 | AI Hub 118 안면 인식 에이징 | 생성 얼굴의 목표 나이 손실 계산 | 전체 MAE 3.92세, 실제 8세 MAE 1.68세 |
| 가족 인지 신원 교사 | AI Hub 045 가족 관계 얼굴 | 생성 얼굴의 신원 손실 계산 | 같은 가족 내 타인 구분 정확도 90.31% |

가족 데이터에서 친척은 같은 사람이 아니다. 같은 `personal_id` 사진만 positive로
사용하고, 같은 `family_id`의 다른 사람은 닮은 외모를 구분해야 하는 hard negative로
사용했다. 원본 데이터의 TL/TS와 VL/VS는 각각 짝지었고, 공식 VL/VS 가족은 학습에서
제외했다. 원본·정렬 얼굴·체크포인트는 라이선스 데이터이므로 Git에 넣지 않는다.

### 8.2 개편한 생성기 손실

`revised` 목적함수는 다음 항목을 함께 최적화한다.

1. 동일 인물 실제 목표 연령 사진에 대한 L1·LPIPS
2. 한국인 나이 교사의 목표 나이 Smooth L1
3. 가족 인지 교사의 성인 원본 및 실제 목표 사진 신원 cosine 손실
4. 얼굴 밖 배경 보존 손실
5. 기존 FRAN 출력에서 지나치게 벗어나지 않는 약한 legacy 보존 손실
6. PatchGAN adversarial 손실

첫 번째 500스텝 실험은 나이 MAE를 크게 줄였지만 성인 원본 신원 유사도가
`0.76991 → 0.59358`로 떨어져 탈락했다. 두 번째 실험은 학습률을 `3e-6`으로 낮추고
신원·배경·legacy 보존 비중을 높였다. 저장된 각 체크포인트를 학습에 쓰지 않은
공식 Validation의 실제 8세 사진 62명으로 다시 평가했다.

| 체크포인트 | 실제 8세 신원 | 성인 원본 신원 | AI Hub 나이 MAE | LPIPS | 판정 |
|---:|---:|---:|---:|---:|---|
| 기존 운영 | 0.31636 | 0.76991 | 12.79세 | 0.70350 | 기준 |
| 100스텝 | 0.32323 | 0.84214 | 16.44세 | 0.69649 | 나이 악화 |
| 200스텝 | 0.32444 | 0.86853 | 18.66세 | 0.68705 | 나이 악화 |
| **300스텝** | **0.32603** | **0.76439** | **8.14세** | **0.67924** | **승격** |
| 400스텝 | 0.31942 | 0.69325 | 4.39세 | 0.66819 | 신원 손실 |
| 500스텝 | 0.31431 | 0.65111 | 3.39세 | 0.66058 | 신원 손실 |

승격 기준은 나이 MAE와 LPIPS가 개선되고, 실제 8세 정답 신원이 악화되지 않으며,
성인 원본 신원 유사도 감소가 `0.01` 이내인 것이다. 300스텝은 네 조건을 모두
통과했다. 400·500스텝은 나이를 더 정확히 만들었지만 사람을 바꾸는 방향으로
움직였으므로 사용하지 않는다. **더 오래 학습한 모델이 더 좋은 모델이 아니다.**

## 9. 3인 전체 파이프라인 게이트

FRAN 단독 출력의 왜곡과 최종 서비스 사진의 품질을 혼동하지 않도록, 학습에 쓰지
않은 3명을 대상으로 다음 세 경로를 같은 입력·프롬프트·시드에서 비교했다.

1. FRAN 없이 FLUX.2 + 개인 Identity LoRA
2. 기존 FRAN 구조 가이드 + FLUX.2 + 개인 Identity LoRA
3. AI Hub 튜닝 FRAN 구조 가이드 + FLUX.2 + 개인 Identity LoRA

각 인물의 실제 8세 사진은 LoRA 학습과 생성에서 봉인하고, 18장 생성이 모두 끝난
뒤 평가에만 열었다. 인물당 성인 사진 5장으로 LoRA를 만들고, 세 경로마다 시드 두
개를 사용해 총 18장을 생성했다.

| 최종 경로 | 실제 8세 신원 | 성인 원본 신원 | InsightFace 나이 MAE | AI Hub 나이 MAE | LPIPS |
|---|---:|---:|---:|---:|---:|
| FLUX + LoRA | 0.25702 | 0.73405 | **21.17세** | 24.66세 | 0.80671 |
| 기존 FRAN + FLUX + LoRA | 0.25525 | 0.79113 | 21.67세 | **24.61세** | 0.80131 |
| 튜닝 FRAN + FLUX + LoRA | **0.25842** | **0.80066** | 22.00세 | 25.09세 | **0.79988** |

세 경로 모두 얼굴 한 명 검출과 기본 품질 검사는 통과했지만, 생성 얼굴의 추정
나이가 약 29~41세에 머물렀다. 시각적으로도 FRAN 원시는 아동 구조를 강하게
만드는 대신 왜곡이 있었고, FLUX 최종화 뒤에는 왜곡과 함께 아동 구조까지 거의
사라져 성인 얼굴로 수렴했다.

따라서 이 실험의 판정은 **튜닝 FRAN을 운영 경로에 연결하지 않음**이다. 추가
FRAN 학습보다 먼저 같은 3명·같은 시드를 유지한 채 LoRA 강도, 편집 강도, 구조
가이드 주입 방식의 소규모 추론 격자를 시험한다. 추정 나이가 8세 방향으로 충분히
움직이면서 실제 8세 신원이 유지되는 설정을 찾은 뒤에만 62명 평가로 확장한다.

`data/experiments/aihub71415_full/full_pipeline_pilot`에 저장한다.
