# 시연 대본

3분 안에 끝내는 것을 목표로 한다. 기능을 다 보여주려 하지 말고
**"확인되지 않은 것을 사실로 만들지 않는다"** 한 가지를 각인시킨다.

## 여는 한 문장

무대에 올라가서 처음 말할 문장이다. 서비스 설명은 이걸로 끝낸다.

> 치매는 기억력만 잃는 병이 아닙니다. 지금이 언제인지, 여기가 어디인지에 대한
> **맥락이 끊어지고**, 그 끊김이 불안과 반복행동으로 나타납니다.
> 가족은 같은 설명을 하루에 몇 번씩 되풀이합니다.
> 저희는 그 맥락을 **가족의 얼굴과 목소리로** 다시 이어줍니다.

**말하지 말 것** — 치료, 예방, 기억 회복. 근거가 없고, 하나라도 입에 담으면
나머지 주장의 신뢰가 같이 떨어진다. (`docs/service_definition.md`)

각 막이 증명하는 축은 아래와 같다. 굳이 소리 내어 말할 필요는 없고,
질문이 들어왔을 때 이 틀로 답한다.

---

## 시작 전 (2분)

```powershell
# 터미널 1 — API와 통합 앱
.\.venv\Scripts\python.exe tools\serve.py --no-reload

# 터미널 2 — 로컬 UI를 바로 수정할 때만 사용
cd frontend
npm run dev

# 시연 데이터 초기화가 필요할 때 한 번 실행
.\.venv\Scripts\python.exe tools\demo_reset.py --med-in 6
```

ElevenLabs와 Anam은 배포 API를 직접 사용하므로 로컬 GPU 터미널이 필요 없다.
Anam 연결이 실패해도 ElevenLabs 음성은 계속 재생된다. MuseTalk을 대체 경로로
따로 시연할 때만 `tools/tts_bridge.py`를 추가로 켠다.

체크리스트

- [ ] **Chrome** 으로 열었는가 (Edge·Safari 는 음성 인식 동작이 다르다)
- [ ] 마이크 권한 허용
- [ ] 스피커 볼륨
- [ ] 어르신·가족 앱에서 서로 다른 역할과 같은 어르신을 선택했는가
- [ ] 가족의 승인된 음성 ID와 Anam avatar ID가 설정 화면에 생성되어 있는가
- [ ] 개발자 도구는 **닫아둘 것**

폰 두 대 시연은 HTTPS인 Render 배포 주소 또는 고정 Cloudflare Tunnel을 사용한다.
Quick Tunnel은 재시작할 때 주소가 바뀌므로 발표용 고정 주소로 간주하지 않는다.
**발표 직전에는 배포하지 않는다.**

## 1막 — 전화가 연결된다 (30초)

> **Connect · 기억을 연결한다**

가족 얼굴 카드를 누른다.

> 손자에게 전화를 겁니다. 손자는 회사에 있어 받지 못합니다.

모핑 영상이 대기 화면으로 재생되며 남은 시간이 초 단위로 표시된다.

> 24초 뒤, 가족이 받지 않으면 준비된 AI가 대신 받습니다.
> 기다리는 시간은 서버가 정합니다. 어르신 폰이 혼자 세는 게 아니라,
> 가족 폰에 실제로 벨이 가고 받았는지를 서버가 판정합니다.

> 지금 보시는 건 여덟 살부터 서른두 살까지의 얼굴입니다.
> 치매가 진행되면 최근 기억부터 사라지기 때문에, 할아버지가 기억하시는
> 어린 시절 얼굴에서 시작해 현재 얼굴까지 데려옵니다.

**말할 것** — 영상은 통화할 때 만드는 게 아니라 가족이 사진을 등록할 때
한 번 만들어 둔다. 그래서 지연이 없다.

---

## 2막 — 거짓 약속을 하지 않는다 (60초)

> **Orient의 안전 경계 · 맥락은 등록된 사실에서만 나온다**

**핵심 장면이다. 여기에 시간을 제일 많이 쓴다.**

말한다:

> **"대웅아, 오늘 집에 오니?"**

AI가 답한다. 오늘 일정이 없으므로 오늘 오겠다고 하지 않는다.
등록된 주말 방문만 이야기한다.

> 여기가 이 서비스의 핵심입니다. 일반 대화 AI는 "응 갈게"라고 답합니다.
> 그게 더 다정하니까요. 그런데 치매 노인은 그 말을 사실로 기억하고
> 하루 종일 현관 앞에서 기다립니다.

이어서 말한다:

> **"우리 예전에 기차 타고 강릉 갔던 거 기억나니? 국수 먹었잖아."**

AI는 사실로 확정하지 않고 되묻는다.

> 등록되지 않은 기억입니다. AI는 맞장구치지 않고 되묻습니다.
> 이 대화는 보호자 확인 대기함으로 넘어갑니다.

---

## 3막 — 위험을 놓치지 않는다 (20초)

> **D축 · AI가 판단하지 않고 보호자에게 넘긴다**

> **"아까 화장실에서 넘어졌는데 일어나기가 힘들구나."**

화면 상단에 노란 띠가 뜬다.

> 낙상으로 판단하고 가족에게 알렸습니다. 소리를 못 들으셔도
> 화면으로 조치된 걸 확인할 수 있습니다.

**끊기** 를 누른다.

---

## 4막 — 약 시간에 먼저 전화한다 (30초)

> **C축 · 실행능력 보조. 지시가 아니라 확인**

대기 화면으로 돌아온 뒤 6분이 되면 전화가 걸려온다.
(리셋할 때 `--med-in` 으로 맞춰둔 시각)

> 이번엔 AI가 겁니다. 보호자가 등록한 복약 시간이 됐기 때문입니다.

**받기** 를 누르면 대웅이가 먼저 말한다.

> 약 이름과 복용량은 AI가 만든 문장이 아닙니다.
> 보호자가 등록한 값을 그대로 읽습니다.

> **"글쎄, 먹었나 안 먹었나 모르겠어."**

AI는 임의로 지시하지 않는다.

> 여기서 "그럼 지금 드세요"라고 하면 안 됩니다. 이미 드셨을 수 있으니까요.
> 확인 후 알려드리겠다고만 합니다.

**끊기**.

---

## 5막 — 가족은 무엇을 받는가 (40초)

> **Care · 인지·행동 변화 관찰**

`localhost:5173/#child` 탭(가족 화면)으로 이동해 **추억함**을 연다.
요양원 담당자 화면은 `#care` 이며 5막에서는 쓰지 않는다.

**① 확인이 필요한 이야기** — 강릉 기차 여행이 올라와 있다.

> 통화에서 나온 미확인 기억입니다. 가족이 승인해야만
> 다음 통화부터 AI가 사실로 이야기합니다.
> **AI가 스스로 기억을 늘리지 못합니다.**

**확인** 을 누른다. (**일부만** 을 고르면 `partial` 로 저장되어 다음
통화에서 AI가 반드시 불확실하게 말한다. 여유가 있으면 이쪽이 더 강한
장면이다.)

**② 통화 기록** — 가족 화면의 **통화** 탭에서 방금 통화를 펼친다.

> 요약, 반복하신 질문 횟수, 복약 상태, 위험 신호가 나옵니다.
> 이 숫자들은 AI가 만든 게 아니라 대화 기록을 집계한 값입니다.

마지막 항목을 가리킨다.

> **안전 규칙이 응답을 고친 횟수.**
> AI가 이런 말을 하려다 규칙에 걸려 바뀌었다는 걸 보호자가 볼 수 있습니다.

## 마무리 한 문장

> 저희가 만든 건 말을 잘하는 AI가 아니라,
> **말하면 안 되는 것을 말하지 않는 AI** 입니다.

## 무너졌을 때

| 증상 | 대응 |
|---|---|
| 음성 인식이 안 됨 | 자막 아래 **글자로 입력** 을 누르고 타이핑. 대본 그대로 진행 |
| 목소리가 안 나옴 | 브리지 터미널이 살아 있는지 먼저 본다. 죽었으면 재실행하고 30초 대기. 그 동안은 자막을 읽으면서 진행 |
| 입이 안 움직임 | 립싱크만 죽은 것이고 목소리는 그대로 나온다. 설계된 폴백이므로 **그냥 진행한다.** 지적받으면 "실패하면 음성으로 넘어가게 해뒀다"고 답한다 |
| 응답이 10초 넘게 안 옴 | 무료 티어 지연. "지금 무료 API로 돌고 있어 느립니다" 라고 말하고 기다림 |
| 전화가 안 걸려옴 | 대기 화면에서 최대 20초. 그래도 안 오면 그냥 **전화 걸기** 를 누름 |
| 모핑 영상이 검게 나옴 | 새로고침. 그래도 안 되면 사진 전환으로 자동 대체되므로 그대로 진행 |
| 화면이 하얗게 됨 | 새로고침. Vite 가 죽었으면 `npm run dev` 재실행 |

**라이브 시연이 위험하면 미리 녹화한 영상을 틀고 설명한다.**
발표 전날 반드시 한 번 녹화해 둘 것.

## 예상 질문

**"그냥 ChatGPT에 프롬프트 넣은 거 아닌가요?"**
프롬프트는 1차 방어일 뿐입니다. 모델이 규칙을 어길 때가 있어서
응답을 검사하는 층을 따로 뒀습니다. 37개 시나리오로 회귀 테스트를 돌립니다.
프롬프트만 썼을 때와 안전 계층을 켰을 때의 통과율을 같은 명령으로 비교할 수
있습니다(`tools/eval.py --raw` 와 비교).

> 발표 직전에 `python tools/eval.py --sleep 5` 를 한 번 돌려 **그날의 숫자**로
> 말한다. 통과율은 모델·프롬프트에 따라 바뀌므로 외운 숫자를 말하지 않는다.

**"음성이 실제 가족 목소리인가요?"**
네. 가족이 직접 녹음하고 승인한 음성으로 만든 복제 음성입니다. 합성은
ElevenLabs API로 처리하며, 공급자에 남는 식별자는 서버 DB에만 두고 브라우저에는
단기 세션 토큰만 내려보냅니다. 등록·승인 전에는 어떤 음성도 만들지 않습니다.
가족의 생체정보를 외부 업체에 넘기지 않는 것이 설계 조건이었습니다.

**"입 모양이 말과 안 맞는데요?"**
모핑 인트로가 끝난 뒤부터는 실제 립싱크가 붙습니다. 발화당 4초 정도이고,
아바타를 미리 캐시해 상주 워커에서 돌리기 때문에 가능합니다.
**실패하면 같은 목소리의 음성으로 자동 전환되고 통화는 끊기지 않습니다.**
인트로 구간에서 입이 안 맞는 건 그 구간은 사전 렌더링 영상이기 때문입니다.

**"결국 치매 치료나 예방에 도움이 되나요?"**
아닙니다. 그건 저희 목표가 아니고, 근거도 없습니다.
저희가 말할 수 있는 건 네 가지입니다 — 현재 상황 이해 지원, 정서적 안정,
생활 행동 지원, 보호자 부담 감소. 치료 효과를 주장하는 순간
나머지 주장의 신뢰도 같이 떨어진다고 봤습니다.

**"현재 맥락을 알려준다면서, 틀린 정보를 주면 더 위험하지 않나요?"**
그래서 **맥락은 등록된 사실에서만 나옵니다.** 날짜와 요일은 서버가 계산하고,
일정과 약은 보호자가 등록한 값입니다. 등록되지 않은 것은 맥락으로도
말하지 않습니다. 예를 들어 지금 어디 계신지는 시스템이 모르기 때문에
"집에 계세요"라고 하지 않습니다. 그럴듯하지만 근거가 없으니까요.

**"어린이 사진은 어떻게 하셨나요?"**
상용 영상 생성 모델은 아동 이미지를 정책상 거부합니다.
그 구간만 다른 모델로 처리했고, 실패하는 경우를 대비해
사진 전환으로 자동 대체되는 경로를 넣었습니다.

**"실제 치매 노인에게 테스트했나요?"**
하지 않았습니다. 동의와 윤리 절차가 필요합니다.
현재 데이터는 전부 가상이며, 실제 데이터를 쓰려면 무료 API 티어부터
벗어나야 합니다. 요청 내용이 모델 개선에 사용될 수 있기 때문입니다.
