# 얼굴 연령 변환

이 문서는 제품에 이미 포함된 연령 타임라인과 AI Hub 데이터로 개선 중인 후보
생성 실험을 구분하고, 현재 실행 가능한 범위를 하나의 기준으로 정리한다.

## 1. 제품 생성 계약

제품은 성인 사진에서 8세 사진을 한 번에 만들지 않는다. 현재 사진에서 시작해
인접한 연령 단계별로 완성 사진 후보를 만들고, 가족이 선택한 사진만 다음 단계의
입력으로 사용한다. 예를 들어 기준 사진이 38세라면 다음과 같이 진행한다.

```text
38세 기준 사진
  → 32세 후보 6장 생성(필요 시 최대 8장) → 자동 검증 상위 4장 → 가족 선택
  → 26세 후보 6장 생성(필요 시 최대 8장) → 자동 검증 상위 4장 → 가족 선택
  → 20세 후보 4장 → 선택
  → 15세 후보 4장 → 선택
  → 11세 후보 4장 → 선택
  → 8세 후보 4장 → 최종 선택
  → 승인된 연령 사진으로 모핑 영상 생성
```

실제 제품에서는 현재 나이와 단계별 검증 결과에 따라 중간 연령을 추가할 수 있다.
성인에서 8세로 바로 내려가는 직접 생성 경로는 신원과 아동 구조가 모두 불안정해
제품 및 후보 화면에서 제거했다.

| 단계 | 모델·기술 | 역할 | 학습 여부 |
|---|---|---|---|
| 입력 품질 검사 | OpenCV YuNet | 얼굴 수·크기·기울기·선명도·밝기 검사 | 고정 |
| 후보 사진 생성 | FLUX.2 Klein 4B Inpaint | 얼굴 영역을 목표 나이로 다시 그림 | 고정 |
| 개인 얼굴 유지 | Identity LoRA | 등록한 사람의 얼굴 특징을 생성기에 제공 | 사용자별 학습 |
| 성장 구조 보조 | FRAN residual U-Net | 턱·볼·하안면 등 성장 방향의 내부 구조 가이드 | 데이터 실험 대상 |
| 신원 검증 | InsightFace | 생성 사진과 기준 사진의 얼굴 임베딩 비교 | 고정 |
| 연령 검증 | InsightFace·MiVOLO | 목표 나이 적합도를 독립적으로 추정 | 고정 |
| 구조 검증 | 3DDFA-V2 | 포즈 영향을 줄인 얼굴 구조 변화 확인 | 고정 |
| 키프레임 정렬 | YuNet 5점 랜드마크 | 눈과 얼굴 위치를 맞춰 흔들림 완화 | 고정 |
| 영상 보간 | RIFE ONNX | 승인된 연령 사진 사이의 중간 프레임 생성 | 고정 |
| 통화 아바타 | Anam | 현재 가족 얼굴을 말하는 영상으로 표현 | 공급자 모델 |

FRAN 결과는 완성 사진이 아니다. FLUX 생성 방향을 보조하는 내부 구조 가이드이며,
FRAN 단독 출력은 후보 화면에 절대 노출하지 않는다.

완성 자산은 다음 위치에 있다. 실행에 필요한 후보·키프레임·영상과 최종 검수
메타데이터만 저장소에 포함하고, 재생성 과정의 중간 산출물은 로컬에 둔다.

- 영상: `data/faces/morph.mp4` (저장소 포함, Git LFS)
- 키프레임: `data/faces/aligned/age_path_final/` (저장소 포함)
- 연령 계획: `data/faces/age_plan.json` (저장소 포함)
- 검증 메타데이터: `data/faces/morph.json` (저장소 포함)
- 최종 QC 시트: `data/faces/morph_qc.png` (저장소 포함)

## 2. 이번 개선의 목표

기존 방식은 한 번 성공한 연령 경로를 만들었지만, 새로운 사람에게 같은 품질을
안정적으로 재현하고 여러 후보 중 근거 있는 추천을 제공하는 자동화가 부족했다.
이번 실험은 생성 모델을 무조건 크게 재학습하는 작업이 아니라 다음 세 가지를
개선한다.

1. 목표 나이가 피부 톤 변화에 그치지 않고 아동 얼굴 구조로 보이게 한다.
2. 성인 얼굴의 신원을 유지하되 목표 나이 정확도와 균형을 맞춘다.
3. 자동 추천 한 장으로 확정하지 않고 각 연령의 완성 후보 네 장과 추천 이유를
   가족에게 제공한다.

## 3. 데이터 사용

### AI Hub 71415 — 안면 인식 에이징 이미지

- 동일 인물의 여러 연령 사진으로 연령 변화와 목표 8세 평가 구조를 만든다.
- 공식 Training 인물만 학습·튜닝에 사용하고 공식 Validation 인물은 최종 시험에
  남긴다.
- 사람 단위로 분리해 같은 인물이 학습과 평가 양쪽에 들어가지 않게 한다.
- 평가 인물의 실제 과거 사진은 후보 생성·자동 순위 학습에 노출하지 않고 모든
  단계 생성이 끝난 뒤 마지막 평가에서만 연다.

### AI Hub 528 — 가족 관계 얼굴 이미지

- 가족 간 유사성과 동일 인물 보존을 구별하는 신원 선별기 연구에 사용한다.
- 생성기의 목표 나이 변환을 직접 학습시키는 데이터로 취급하지 않는다.

원본과 정렬 파생물은 `data/experiments/` 아래 로컬에만 두며 Git에 올리지 않는다.

## 4. 두 제품 모드

| 모드 | 입력 | 의미 |
|---|---|---|
| 현재 사진 추정 | 성인 사진만 | 어린 사진이 없는 사용자의 추정 후보 생성 |
| 어린 시절 사진 보조 | 성인 사진 + 품질을 통과한 어린 사진 | 실제 어린 시절 단서를 별도 LoRA로 보조 |

어린 사진은 `train_primary`, `reference_only`, `reject`로 나눈다. 얼굴 픽셀 크기,
선명도, 밝기, 대비, 기울기를 자동 검사하고 가림·과한 표정·복잡한 배경은 사람이
확인한다. 낮은 화질을 단순 확대했다고 학습 가능 사진으로 승격하지 않는다.

어린 시절 사진 보조 모드에서도 일부 사진만 학습하고 최소 한 장은 평가용으로
봉인한다. 성인 신원 LoRA와 어린 근거 LoRA를 섞어 하나로 만들지 않는다.

## 5. 단계별 후보 생성과 소규모 연령 학습

기준 경로는 기존 FLUX 순차 생성이고, 개선 경로는 같은 순차 생성기에 AI Hub
71415의 동일 인물 인접 연령 쌍을 학습한 paired FLUX LoRA를 약하게 결합한 것이다.
LoRA가 완성 얼굴을 대신 만드는 것이 아니라, 같은 사람을 다음 목표 연령으로
바꾸는 방향을 보정한다.

```text
기존 경로: 선택한 직전 사진 → 고정 FLUX → 완성 후보
개선 경로: 선택한 직전 사진 → 고정 FLUX + paired-age LoRA → 완성 후보
```

학습 쌍은 `38→32`, `32→26`, `26→20`, `20→15`, `15→11`, `11→8`로
구성한다. 동일 인물·동일 단계의 과도한 반복을 막기 위해 한 사람당 단계별 한 쌍만
사용한다. 현재 소규모 시험은 각 목표 연령 64쌍, 총 384쌍으로 진행한다.

```powershell
# 두 데이터셋 전처리·분할 검증
.\.venv\Scripts\python.exe tools\face_aging\aihub_face_dataset_audit.py

# 학습 미사용 평가 인물 준비
.\.venv-flux2\Scripts\python.exe tools\face_aging\aihub71415_sequential_flux_eval.py prepare

# 기준 및 개선 순차 경로 생성
.\.venv-flux2\Scripts\python.exe tools\face_aging\aihub71415_sequential_flux_eval.py generate-baseline
.\.venv-flux2\Scripts\python.exe tools\face_aging\aihub71415_sequential_flux_eval.py generate-adapted

# 봉인한 실제 과거 사진을 마지막에 열어 평가 화면 작성
.\.venv-flux2\Scripts\python.exe tools\face_aging\aihub71415_sequential_flux_eval.py evaluate
```

생성 시 각 단계에서 먼저 여섯 장을 만들고, 품질 통과 후보가 네 장 미만일 때만
최대 두 장을 더 만든다. 얼굴 미검출·다중 얼굴·심한 흐림·노출 실패·신원 붕괴는
제거하고 완성 사진 상위 네 장만 화면에 보인다. 가족이 선택한 사진이 다음 단계의
부모 사진이 된다. 자동 평가 파일은 실험 폴더에 남지만 실제 과거 정답 사진은
`evaluate` 전까지 열지 않는다.

`tools/face_aging/aihub71415_four_candidate_pilot.py`의 직접 생성 비교 도구는 폐기되었으며 새
실험과 제품에서 사용하지 않는다.

## 6. 후보 선별과 사용자 선택

얼굴 미검출, 다중 얼굴, 심한 흐림·노출 문제는 먼저 하드 게이트로 제거한다.
통과 후보는 다음 근거로 순위를 계산하되 최종 사진은 사용자가 고른다.

- 목표 나이 적합도
- 현재·과거 기준 사진에 대한 신원 보존도
- 얼굴 인식에 사용할 수 있는 수준의 이미지 품질
- 인접 연령 사진과의 연속성(경로가 있을 때만)

논문이 합의한 보편적 고정 가중치는 없으므로 임의 비율을 사용하지 않는다.
블라인드 쌍대비교에서 사람이 고른 결과를 비음수·합 1의 가중치로 학습하고,
사람 단위 교차검증으로 새 사람에게도 선택을 예측하는지 확인한다. 실제 8세 정답은
이 가중치 학습에 쓰지 않는다.

추천 이유는 LLM이 만들지 않고 수치 차이로 조립한다.

- `목표 8세에 가장 가까운 후보`
- `기준 사진의 얼굴 특징이 가장 안정적으로 남은 후보`
- `나이 적합도와 신원 보존의 균형이 가장 좋은 후보`
- `자동 추천 차이가 작아 가족의 직접 선택이 필요함`

## 7. 현재 실행 상태와 확대 조건

- AI Hub 71415는 45,200건·904명, AI Hub 528/045는 오류·중복 제외 후
  109,287건·905가족으로 인덱싱했다.
- 71415는 `subject_id`, 528/045는 `family_id` 단위로 train/validation/test를
  분리했고 두 데이터셋 모두 그룹 누출은 0건이다.
- 528/045의 파일명·라벨 대응이 불명확한 156건은 추측해 고치지 않고 제외했다.
- 학습 미사용 자동 평가 인물은 71415 test의 `0974`이며, 38세 기준 사진만 열고
  32·26·20·15·11·8세 실제 사진은 평가 전까지 봉인한다.
- paired FLUX LoRA 300-step 소규모 시험을 완료했고, 학습 미사용 인물 `0974`에
  대해 같은 입력·시드·순차 연령 경로로 기존 FLUX와 LoRA 결합 경로를 비교했다.
- 선택 후보 기준 실제 같은 연령 사진과의 신원 유사도는 `0.42851 → 0.43310`,
  목표 연령 평균 절대오차는 `6.83세 → 6.67세`로 변했다. 개선 폭은 각각
  `+0.00459`, `-0.17세`에 불과해 실질적 성능 향상으로 판정하지 않는다.
- 특히 목표 15·11·8세 후보가 모두 약 20~21세로 추정되었다. 8세 후보를
  육안으로 확인해도 기본 경로와 LoRA 경로 모두 성인 얼굴 비율이 남아 있었다.
- 따라서 300-step paired-age LoRA는 제품 모델로 승격하지 않으며, 가족 데이터
  선별기와 정훈·미영·대웅·유진 확장도 보류한다.

가족 데이터는 현재 동일 가족이라는 이유만으로 더 같은 사람처럼 보인다고 볼 수
있는 분리력이 확인되지 않았다. 따라서 가족 선별기는 아직 제품 경로에 넣지 않는다.
먼저 연령 LoRA의 홀드아웃 개선을 확인한 뒤 별도 검증을 통과할 때만 추가한다.

비교 결과와 후보 이미지는 다음 로컬 산출물에서 확인한다.

- 정량 결과: `data/experiments/aihub71415_sequential_flux_eval/evaluation_report.json`
- 육안 비교: `data/experiments/aihub71415_sequential_flux_eval/review/index.html`
- 데이터 감사: `data/experiments/face_dataset_audit/report.json`

다음 실험은 학습 스텝을 임의로 늘리는 방식으로 진행하지 않는다. 먼저
`6~10세`, `11~17세` 전환 쌍의 표집 비중, LoRA 적용 강도, 목표 연령 조건이
실제로 생성 결과를 움직이는지 한 인물의 작은 격자로 확인한다. 8세 후보의 추정
나이가 명확하게 내려가고 신원 유사도가 유지될 때만 전체 홀드아웃으로 확장한다.

# 2부. AI Hub 71415 실험 파이프라인 (연구 로그)

이 파이프라인은 `안면 인식 에이징 이미지 데이터(71415)`를 이용해 한국인 연령
변환의 구조 기준을 학습하고, 실제 8세 사진을 숨긴 상태에서 현재 생성기와 새
모델을 비교하기 위한 기반이다. 원본 얼굴과 파생 정렬 사진은 Git에 올리지 않는다.

## 1. 샘플 인덱싱

원본 ZIP을 풀지 않고 라벨과 이미지의 대응 관계만 기록한다.

```powershell
.\.venv\Scripts\python.exe tools\face_aging\aihub71415_index.py `
  --archive "C:\path\to\Sample.zip" `
  --output-dir data\experiments\aihub71415_sample\index
```

전체 데이터가 원천·라벨 ZIP으로 나뉘면 라벨 ZIP을 `--archive`, 원천 ZIP을
`--image-archive`로 전달한다.

전체 904개 묶음을 한 번에 인덱싱할 때는 압축을 풀지 않고 데이터셋 루트를
전달한다. 파일 이름의 대소문자 차이와 일부 라벨에 포함된 `.png` 확장자는
정규화해서 원천 사진과 연결한다.

```powershell
.\.venv\Scripts\python.exe tools\face_aging\aihub71415_index.py `
  --dataset-root "C:\path\to\118.안면 인식 에이징(aging) 이미지 데이터" `
  --output-dir data\experiments\aihub71415_full\index
```

## 2. AI Hub 5점 좌표로 얼굴 정렬

```powershell
.\.venv\Scripts\python.exe tools\face_aging\aihub71415_prepare.py `
  --archive "C:\path\to\Sample.zip" `
  --manifest data\experiments\aihub71415_sample\index\manifest.jsonl `
  --output-dir data\experiments\aihub71415_sample\prepared
```

별도 얼굴 검출 결과를 정답처럼 쓰지 않는다. 라벨의 눈·코·입 5점을 사용해
similarity alignment를 수행하고 오차를 매니페스트에 남긴다.

## 6. FRAN 파인튜닝

FRAN 입력과 출력 구조는 유지한다. 입력은 RGB 3채널, 현재 나이 맵, 목표 나이
맵의 5채널이고 생성기는 원본에 더할 RGB residual을 예측한다. 생성기와
PatchGAN 판별기는 기존 공개 체크포인트에서 시작한다.

AI Hub 사진은 같은 사람이어도 표정·자세·조명·배경이 서로 다르다. 따라서 실제
과거 사진을 목표 픽셀로 직접 맞추는 `paired` 목적은 비교 실험으로만 두고,
기본값은 `distribution`으로 정했다.

- 고정 교사 FRAN 결과와 L1·LPIPS로 가까운 상태를 유지한다.
- AI Hub 실제 사진으로 판별기가 한국인 연령 분포를 학습한다.
- 생성기는 목표 나이 판별 손실을 작게 받아 촬영 조건을 복사하지 않고 분포만
  보정한다.
- 처음 50스텝은 판별기만 적응시키고 이후 생성기를 함께 갱신한다.
- 원본 `best_unet_model.pth`는 덮어쓰지 않고 실험 폴더에 생성기 전용 및 전체
  재개 체크포인트를 함께 저장한다.

학습 환경 준비:

```powershell

```

## 7. 5,000스텝 균형 학습과 최종 판정

전체 195,125쌍을 단순 무작위로 반복하면 사진이 많은 사람과 흔한 연령 구간이
학습을 지배한다. 이를 막기 위해 `balanced_age_gap_subject` 샘플러를 추가했다.

- 사람별 데이터 수의 역수로 가중하여 특정 인물이 과대표집되지 않게 한다.
- 목표 연령을 `0~5 / 6~10 / 11~17 / 18~29 / 30~44 / 45+`로 나눠 균형화한다.
- 연령 차이를 소·중·대 세 구간으로 나눠 큰 연령 변환도 계속 보게 한다.
- 서비스 핵심인 목표 8세 주변(6~10세)은 2배 가중한다.
- 극단 가중치는 0.1~10 범위로 제한한 뒤 평균 1로 정규화한다.

실제 기대 표집 비율은 목표 6~10세 29.37%, 나머지 연령 구간 각각
13.37~14.61%였고, 연령 차이 소·중·대는 각각 32.79%, 33.07%, 34.14%였다.
이 설정으로 512px, batch 1, AMP, 학습률 `1e-5`에서 5,000스텝을 실행했다.

| 항목 | 시작 | 3,500스텝 | 5,000스텝 |
|---|---:|---:|---:|
| 검증 L1 | 0.246416 | **0.246030** | 0.246121 |
| 검증 LPIPS | 0.680441 | **0.678756** | 0.679229 |
| 고정 교사 대비 L1 변화 | 0 | - | 0.002080 |

- 총 실행 시간: 2,307.7초(38분 28초)
- 평균 실행 시간: 0.462초/스텝
- 최대 할당 GPU 메모리: 1.689 GiB
- 내부 검증 최저점은 3,500스텝이었다.

내부 검증 사진은 실제 과거 사진과 촬영 조건이 달라 최종 판정에 충분하지 않다.
따라서 학습에 한 번도 쓰지 않은 공식 Validation 인물 중 정확한 8세 사진을 가진
62명을 대상으로, 각 인물의 가장 나이 든 성인 사진만 입력하고 실제 8세 사진은
정답 평가에만 사용했다. 모든 사진은 AI Hub 5점 라벨로 먼저 고정 정렬했으므로,
평가 단계에서 얼굴 검출기의 임계값을 다시 통과시키지 않고 같은 고정 좌표에서
InsightFace 임베딩과 나이 추정을 계산했다.

| 지표(62명 평균) | 기존 모델 | 3,500스텝 | 5,000스텝 |
|---|---:|---:|---:|
| 실제 8세 사진과 신원 유사도 | 0.31636 | 0.31743 | 0.31635 |
| 성인 입력과 신원 유사도 | 0.76991 | 0.78545 | 0.77940 |
| 목표 8세 나이 절대오차 | **16.58세** | 17.95세 | 17.73세 |
| 실제 8세 사진 대비 L1 | 0.22333 | 0.22267 | **0.22255** |
| 실제 8세 사진 대비 LPIPS | 0.70350 | **0.69734** | 0.69933 |

3,500스텝의 실제 8세 신원 유사도 증가는 `+0.00107`로 작고, 95% 부트스트랩
신뢰구간 `[-0.00146, +0.00359]`이 0을 포함했다. 반면 목표 나이 오차는
`+1.37세` 악화되었다. 성인 입력과의 유사도가 더 높아진 것은 신원 보존에는
긍정적일 수 있지만, 이번 실험에서는 얼굴이 충분히 어려지지 않은 결과와 함께
나타났다. 5,000스텝도 실제 8세 신원 유사도는 기존과 사실상 같고 나이 오차가
`+1.15세` 악화되었다.

따라서 **5,000스텝 후보와 3,500스텝 후보 모두 서비스 모델로 승격하지 않는다.**
기존 `best_unet_model.pth`도 덮어쓰지 않았다. 더 많은 스텝보다 다음 목적함수
변경이 먼저다.

1. 고정 교사 보존 손실의 비중을 낮추는 짧은 2단계 학습을 별도 실험한다.
2. 고정 InsightFace 임베딩의 신원 보존 손실을 추가한다.
3. 고정 나이 추정기의 목표 나이 손실을 추가하되, 추정기 편향을 확인하기 위해
   여러 나이 구간의 실제 사진으로 먼저 보정한다.
4. 표정·자세·조명이 가까운 동일 인물 쌍을 우선 표집하고, 품질이 낮거나 가림이
   큰 사진은 학습 비중을 낮춘다.
5. 8세 홀드아웃에서 실패가 큰 인물·연령 차이를 다음 학습의 hard example로
   재표집하되 공식 Validation 101명은 끝까지 학습에 넣지 않는다.

L1·LPIPS는 종단 사진의 표정·자세·조명 차이에 영향을 받으므로 보조 지표로만
사용한다. 다음 후보도 신원 보존, 목표 나이, 블라인드 사람 평가를 함께 통과해야
서비스에 연결한다.

## 8. 나이·신원 목적함수 개편과 운영 승격

단순 재구성 손실은 얼굴이 실제 8세에 가까워졌는지와 같은 사람인지 직접 측정하지
못했다. 이를 보완하기 위해 운영 모델 수를 늘리지 않는 **학습 전용 교사 두 개**를
별도로 만들었다. 생성 서비스에는 여전히 FRAN과 후처리 모델만 로드한다.

### 8.1 학습 전용 교사

| 교사 | 학습 데이터 | 역할 | 공식 검증 결과 |
|---|---|---|---:|
| 한국인 나이 교사 | AI Hub 118 안면 인식 에이징 | 생성 얼굴의 목표 나이 손실 계산 | 전체 MAE 3.92세, 실제 8세 MAE 1.68세 |
| 가족 인지 신원 교사 | AI Hub 045 가족 관계 얼굴 | 생성 얼굴의 신원 손실 계산 | 같은 가족 내 타인 구분 정확도 90.31% |

가족 데이터에서 친척은 같은 사람이 아니다. 같은 `personal_id` 사진만 positive로
사용하고, 같은 `family_id`의 다른 사람은 닮은 외모를 구분해야 하는 hard negative로
사용했다. 원본 데이터의 TL/TS와 VL/VS는 각각 짝지었고, 공식 VL/VS 가족은 학습에서
제외했다. 원본·정렬 얼굴·체크포인트는 라이선스 데이터이므로 Git에 넣지 않는다.

### 8.2 개편한 생성기 손실

`revised` 목적함수는 다음 항목을 함께 최적화한다.

1. 동일 인물 실제 목표 연령 사진에 대한 L1·LPIPS
2. 한국인 나이 교사의 목표 나이 Smooth L1
3. 가족 인지 교사의 성인 원본 및 실제 목표 사진 신원 cosine 손실
4. 얼굴 밖 배경 보존 손실
5. 기존 FRAN 출력에서 지나치게 벗어나지 않는 약한 legacy 보존 손실
6. PatchGAN adversarial 손실

첫 번째 500스텝 실험은 나이 MAE를 크게 줄였지만 성인 원본 신원 유사도가
`0.76991 → 0.59358`로 떨어져 탈락했다. 두 번째 실험은 학습률을 `3e-6`으로 낮추고
신원·배경·legacy 보존 비중을 높였다. 저장된 각 체크포인트를 학습에 쓰지 않은
공식 Validation의 실제 8세 사진 62명으로 다시 평가했다.

| 체크포인트 | 실제 8세 신원 | 성인 원본 신원 | AI Hub 나이 MAE | LPIPS | 판정 |
|---:|---:|---:|---:|---:|---|
| 기존 운영 | 0.31636 | 0.76991 | 12.79세 | 0.70350 | 기준 |
| 100스텝 | 0.32323 | 0.84214 | 16.44세 | 0.69649 | 나이 악화 |
| 200스텝 | 0.32444 | 0.86853 | 18.66세 | 0.68705 | 나이 악화 |
| **300스텝** | **0.32603** | **0.76439** | **8.14세** | **0.67924** | **승격** |
| 400스텝 | 0.31942 | 0.69325 | 4.39세 | 0.66819 | 신원 손실 |
| 500스텝 | 0.31431 | 0.65111 | 3.39세 | 0.66058 | 신원 손실 |

승격 기준은 나이 MAE와 LPIPS가 개선되고, 실제 8세 정답 신원이 악화되지 않으며,
성인 원본 신원 유사도 감소가 `0.01` 이내인 것이다. 300스텝은 네 조건을 모두
통과했다. 400·500스텝은 나이를 더 정확히 만들었지만 사람을 바꾸는 방향으로
움직였으므로 사용하지 않는다. **더 오래 학습한 모델이 더 좋은 모델이 아니다.**

## 9. 3인 전체 파이프라인 게이트

FRAN 단독 출력의 왜곡과 최종 서비스 사진의 품질을 혼동하지 않도록, 학습에 쓰지
않은 3명을 대상으로 다음 세 경로를 같은 입력·프롬프트·시드에서 비교했다.

1. FRAN 없이 FLUX.2 + 개인 Identity LoRA
2. 기존 FRAN 구조 가이드 + FLUX.2 + 개인 Identity LoRA
3. AI Hub 튜닝 FRAN 구조 가이드 + FLUX.2 + 개인 Identity LoRA

각 인물의 실제 8세 사진은 LoRA 학습과 생성에서 봉인하고, 18장 생성이 모두 끝난
뒤 평가에만 열었다. 인물당 성인 사진 5장으로 LoRA를 만들고, 세 경로마다 시드 두
개를 사용해 총 18장을 생성했다.

| 최종 경로 | 실제 8세 신원 | 성인 원본 신원 | InsightFace 나이 MAE | AI Hub 나이 MAE | LPIPS |
|---|---:|---:|---:|---:|---:|
| FLUX + LoRA | 0.25702 | 0.73405 | **21.17세** | 24.66세 | 0.80671 |
| 기존 FRAN + FLUX + LoRA | 0.25525 | 0.79113 | 21.67세 | **24.61세** | 0.80131 |
| 튜닝 FRAN + FLUX + LoRA | **0.25842** | **0.80066** | 22.00세 | 25.09세 | **0.79988** |

세 경로 모두 얼굴 한 명 검출과 기본 품질 검사는 통과했지만, 생성 얼굴의 추정
나이가 약 29~41세에 머물렀다. 시각적으로도 FRAN 원시는 아동 구조를 강하게
만드는 대신 왜곡이 있었고, FLUX 최종화 뒤에는 왜곡과 함께 아동 구조까지 거의
사라져 성인 얼굴로 수렴했다.

따라서 이 실험의 판정은 **튜닝 FRAN을 운영 경로에 연결하지 않음**이다. 추가
FRAN 학습보다 먼저 같은 3명·같은 시드를 유지한 채 LoRA 강도, 편집 강도, 구조
가이드 주입 방식의 소규모 추론 격자를 시험한다. 추정 나이가 8세 방향으로 충분히
움직이면서 실제 8세 신원이 유지되는 설정을 찾은 뒤에만 62명 평가로 확장한다.

재현 도구는 `tools/face_aging/aihub71415_full_pipeline_pilot.py`, 결과는 Git 제외 경로인
`data/experiments/aihub71415_full/full_pipeline_pilot`에 저장한다.

## 10. 300스텝 paired FLUX LoRA 순차 경로 평가

FRAN 단독 출력이나 성인→8세 직접 생성을 평가하지 않고, 제품 계약과 같은
`38→32→26→20→15→11→8세` 순차 경로에서 paired FLUX LoRA의 효과를 분리해
확인했다. AI Hub 71415 training 인물의 인접 연령 쌍 384개로 rank 16 LoRA를
300스텝 학습했다. 학습 미사용 test 인물 `0974`의 38세 사진만 생성 입력으로
열었고, 실제 32·26·20·15·11·8세 사진은 모든 생성이 끝날 때까지 봉인했다.

기본 경로와 LoRA 경로는 동일한 입력 사진, 후보 수, 시드, 프롬프트와 자동 선별
규칙을 사용했다. 차이는 LoRA 적용 여부와 scale `0.35`뿐이다.

| 지표 | 기본 순차 경로 | 300스텝 LoRA | 변화 |
|---|---:|---:|---:|
| 선택 후보 실제 동연령 신원 유사도 | 0.428506 | 0.433098 | +0.004592 |
| 상위 4장 실제 동연령 신원 유사도 | 0.417704 | 0.420357 | +0.002653 |
| 선택 후보 목표 연령 MAE | 6.833세 | 6.667세 | -0.167세 |
| 상위 4장 목표 연령 MAE | 7.167세 | 7.042세 | -0.125세 |

수치상 방향은 개선이지만 폭이 매우 작다. 더 중요한 실패는 아동 구간이다.

| 목표 연령 | 생성 후보 추정 연령 |
|---:|---:|
| 32세 | 20~23세 |
| 26세 | 21~22세 |
| 20세 | 20~22세 |
| 15세 | 20세 |
| 11세 | 20~21세 |
| 8세 | 20~21세 |

두 경로 모두 15세 아래에서 약 20세 얼굴로 수렴했다. 8세 후보를 실제 8세
사진과 육안 비교해도 피부가 매끈해졌을 뿐 아동의 얼굴 비율·턱·볼 구조로 충분히
변하지 않았다. 따라서 이 LoRA는 운영 모델로 승격하지 않고 가족 선별기와 네 명
페르소나 확장을 시작하지 않는다.

평가 과정에서 512px 정렬 사진처럼 얼굴이 프레임을 꽉 채운 경우 InsightFace가
얼굴을 놓치는 문제가 확인되었다. 원본 픽셀은 바꾸지 않고 평균색 20% 여백을
추가해 한 번만 재검출하도록 평가기를 보완했다. 이 변경은 생성 품질을 높이는
처리가 아니라 동일한 평가 입력을 안정적으로 측정하기 위한 검출 보정이다.

다음 실험의 순서는 다음과 같다.

1. 아동 연령 쌍 표집 비중과 LoRA scale을 작은 격자로 비교한다.
2. 한 명의 8세 결과가 실제로 아동 구간으로 이동하는 설정만 남긴다.
3. 신원 유사도 하락이 없는지 확인한다.
4. 그 뒤에만 여러 미학습 인물과 가족 선별기로 확장한다.

결과는 `data/experiments/aihub71415_sequential_flux_eval/`에 저장되며 정량 결과는
`evaluation_report.json`, 육안 검토 화면은 `review/index.html`이다.
