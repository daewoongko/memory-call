시스템 구성도

가족이 사진과 목소리를 등록하는 순간부터 보호자 손에 리포트가 도착하기까지, 무엇이 어떤 순서로 만들어지는지를 세 장으로 나눠 그렸다. ① 전체 흐름 → ② 구성 요소 → ③ 얼굴 연령 변환.

①

전체 흐름 — 등록에서 리포트까지

왼쪽 끝은 사람이 하고, 가운데는 기계가 하고, 오른쪽 끝은 다시 사람에게 돌아온다. 가장 중요한 선은 맨 아래 되돌아오는 화살표다 — AI 는 스스로 기억을 늘리지 못한다.

②와 ③ 사이가 이 서비스의 성격을 정한다 — 통화 중에 새로 만들어지는 것은 문장뿐이고, 얼굴·목소리·기억은 전부 통화 전에 사람이 승인한 자산이다.
②

시스템 구성도 — 무엇이 무엇을 부르는가

서버는 하나다. 상주 스케줄러도, 메시지 큐도, 관리형 SFU 도 없다. 외부 공급자는 넷뿐이고 각각 정확히 하나의 창구 모듈만 통과한다.

서버는 상태를 가진 유일한 지점이다. 외부 공급자를 창구 모듈 하나로 묶어 둔 이유는 모델 교체가 환경변수 몇 줄로 끝나야 하기 때문이다.
  • 서버가 규칙으로 확정하는 것
  • 외부 AI 공급자 (비결정적)
  • 안전 검사 · 차단
  • 사람의 승인이 필요한 지점
③

얼굴 연령 변환 — 사진 한 장에서 모핑 영상까지

성인 사진에서 8세 사진을 한 번에 만들지 않는다. 인접한 연령 단계마다 후보를 만들고 자동 검증으로 추리고, 가족이 고른 사진만 다음 단계의 입력이 된다. 직접 생성 경로는 신원과 아동 구조가 모두 불안정해 제품에서 제거했다.

가족 선택이 파이프라인 한가운데 들어가 있는 것이 핵심이다. 자동 점수는 후보를 추리기만 하고, 무엇이 이 사람의 얼굴인지는 사람이 정한다.

ElevenLabs 만 실제 로고 형태(막대 두 개 + 워드마크)로 그렸다. OpenAI · Anam · MuseTalk · FLUX 는 브랜드 자산 없이 그린 중립 표기이므로, 발표 자료에 쓸 때는 각 브랜드가 배포하는 공식 SVG 로 갈아끼우는 편이 좋다. 방법은 아래 3번.

고치는 법

세 군데만 알면 된다. 나머지는 건드릴 일이 없다.

  1. 노드를 옮긴다

    각 상자는 translate(x, y) 하나로 위치가 정해진다. 상자 안의 글자 좌표는 상자 기준이라 같이 따라 움직인다.

    <g class="node" transform="translate(552, 606)">
  <rect class="box b" width="186" height="56" rx="9"/>
  ...
</g>

  2. 색(의미)을 바꾼다

    class="box" 뒤에 붙는 한 글자가 의미를 정한다. t 규칙 확정 · b 외부 공급자 · r 안전 차단 · a 사람 승인. 아무것도 없으면 중립. 화살표도 같은 규칙이다 — class="edge b", 굵게 하려면 class="edge a thick".

  3. 로고를 갈아끼운다

    공식 SVG 파일을 열어 <path> 만 복사한 뒤, 맨 위 sprite 안에 아래 형태로 붙이고 상자에서 이름으로 부른다. 원본이 24px 기준이면 scale(0.75) 로 18px 에 맞춘다.

    <!-- sprite 안에 정의 -->
<g id="lg-새서비스" fill="currentColor" transform="scale(0.75)">
  <path d="M12 2L2 7l10 5 10-5z"/>
</g>

<!-- 상자 안에서 사용 -->
<use class="lg lg-b" href="#lg-새서비스" x="14" y="9"/>

    fill="currentColor" 를 지우면 안 된다. 지우는 순간 어두운 화면에서 로고가 사라진다.
